# Vetly AI — Internal Version

Vetly AI is a Streamlit-based internal system that generates HR assessment tests directly from a candidate’s resume.  
It helps hiring teams evaluate applicants through tailored questions that match their skills and experience.

---

## Features
- Instant test generation based on resume content
- Technical, behavioral, and personal questions
- Automatic scoring for candidate answers
- Full evaluation report
- Fast and clean English interface

---

## How It Works
1. Upload the resume  
2. Skills and experience are analyzed  
3. Test questions are generated automatically  
4. Candidate answers inside the system  
5. Final evaluation report is displayed

---

## Tech Stack
- Python  
- Streamlit  
- Groq API  
- Advanced language models
